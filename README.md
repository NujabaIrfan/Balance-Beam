# 💰 Balance Beam – Personal Finance Tracker App

**Balance Beam** is a sleek, user-friendly mobile application built with **Kotlin** for the Android platform. Designed to help users take control of their finances, this app provides a seamless experience in managing earnings, expenses, and savings – all in one place.

## ✨ Features

- 🎯 **Budget Setup & Tracking**
  - Set monthly budget limits
  - Monitor progress and receive alerts when nearing or exceeding limits

- 🧾 **Expense & Income Recording**
  - Log daily transactions with ease
  - Simple and clean interface for quick updates

- 🔔 **Smart Notifications**
  - Real-time alerts when approaching budget caps using Android's Notification Manager

- 💾 **Data Persistence**
  - Save user settings and preferences with `SharedPreferences`
  - Persistent data across sessions

- 📂 **Internal Storage & Backup**
  - Export transaction history as JSON files
  - Restore data easily from internal storage

- 🌍 **Custom Preferences**
  - Choose your preferred currency
  - Tailor budget settings to your needs
